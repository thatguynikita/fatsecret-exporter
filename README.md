# FatSecret API 3-Legged OAuth Food Entries Script

Этот скрипт позволяет получать записи о еде из **пользовательских аккаунтов FatSecret** за определенный день, используя **3-Legged OAuth аутентификацию**. 

🔐 **Важно**: Этот скрипт работает с реальными пользовательскими аккаунтами FatSecret.com и может получать личные данные пищевого дневника после авторизации пользователя.

## Особенности

✅ **3-Legged OAuth Flow** - полная поддержка трёхэтапной аутентификации  
✅ **Пользовательские данные** - доступ к реальным дневникам питания FatSecret  
✅ **Разные URL** - корректное использование authentication.fatsecret.com для токенов  
✅ **Сохранение токенов** - возможность сохранить токены для повторного использования  
✅ **Автоматический браузер** - автоматическое открытие страницы авторизации  
✅ **Красивый вывод** - форматированный текстовый вывод с эмодзи и статистикой  

## Как работает 3-Legged OAuth

1. **Шаг 1**: Приложение получает request token от FatSecret
2. **Шаг 2**: Пользователь авторизует приложение через браузер на FatSecret.com
3. **Шаг 3**: Приложение обменивает authorized request token на access token
4. **Шаг 4**: Приложение использует access token для получения пользовательских данных

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Получите API ключи:
   - Зарегистрируйтесь как разработчик на [FatSecret Platform](https://platform.fatsecret.com/api/)
   - Создайте новое приложение
   - Получите **Consumer Key** и **Consumer Secret** (не Client ID/Secret!)

## Использование

### Способ 1: Через переменные окружения (рекомендуется)

```bash
export FATSECRET_CONSUMER_KEY="your_consumer_key"
export FATSECRET_CONSUMER_SECRET="your_consumer_secret"

python fatsecret_3legged_oauth.py --date 2023-10-01 --format text --save-tokens
```

### Способ 2: Через аргументы командной строки

```bash
python fatsecret_3legged_oauth.py \
    --consumer-key "your_consumer_key" \
    --consumer-secret "your_consumer_secret" \
    --date 2023-10-01 \
    --format json
```

### Параметры

- `--date YYYY-MM-DD` - Дата для получения записей (по умолчанию: сегодня)
- `--format {json,text}` - Формат вывода (по умолчанию: json)
- `--consumer-key` - Consumer Key для FatSecret API
- `--consumer-secret` - Consumer Secret для FatSecret API
- `--save-tokens` - Сохранить токены в файл для повторного использования
- `--load-tokens` - Загрузить токены из файла (пропустить аутентификацию)
- `--tokens-file` - Файл для сохранения/загрузки токенов (по умолчанию: fatsecret_tokens.json)
- `--no-browser` - Не открывать браузер автоматически

### Примеры использования

```bash
# Первый запуск с аутентификацией и сохранением токенов
python fatsecret_3legged_oauth.py --date 2023-10-01 --format text --save-tokens

# Повторное использование сохранённых токенов
python fatsecret_3legged_oauth.py --load-tokens --date 2023-10-02

# Получить данные за сегодня в JSON формате
python fatsecret_3legged_oauth.py

# Использование без автоматического открытия браузера
python fatsecret_3legged_oauth.py --no-browser --date 2023-10-01
```

## Процесс аутентификации

При первом запуске скрипт выполнит следующие шаги:

1. 🔑 **Получение request token** от `authentication.fatsecret.com`
2. 🌐 **Открытие браузера** с переходом на страницу авторизации FatSecret
3. 👤 **Авторизация пользователя** - вход в аккаунт FatSecret и разрешение доступа
4. 🔢 **Ввод PIN кода** - копирование кода подтверждения обратно в скрипт
5. 🔐 **Получение access token** для доступа к пользовательским данным
6. 💾 **Сохранение токенов** (опционально) для повторного использования

## Управление токенами

### Сохранение токенов
```bash
# Сохранить в файл по умолчанию (fatsecret_tokens.json)
python fatsecret_3legged_oauth.py --save-tokens

# Сохранить в указанный файл
python fatsecret_3legged_oauth.py --save-tokens --tokens-file my_tokens.json
```

### Использование сохранённых токенов
```bash
# Загрузить из файла по умолчанию
python fatsecret_3legged_oauth.py --load-tokens

# Загрузить из указанного файла  
python fatsecret_3legged_oauth.py --load-tokens --tokens-file my_tokens.json
```

## Важные URLs

Скрипт использует правильные endpoints для 3-Legged OAuth:

- **Request Token**: `https://authentication.fatsecret.com/oauth/request_token`
- **Authorization**: `https://authentication.fatsecret.com/oauth/authorize`  
- **Access Token**: `https://authentication.fatsecret.com/oauth/access_token`
- **API Calls**: `https://platform.fatsecret.com/rest/server.api`

## Обработка ошибок

Скрипт обрабатывает следующие ошибки:
- ❌ Отсутствие или неверные API креденциалы
- ❌ Неверный формат даты
- ❌ Ошибки сети при OAuth запросах
- ❌ Неверный PIN код авторизации
- ❌ Ошибки API при получении данных
- ❌ Проблемы с сохранением/загрузкой токенов

## Безопасность

⚠️  **Важно**: 
- Никогда не передавайте ваши Consumer Key/Secret третьим лицам
- Храните файлы с токенами в безопасном месте
- Не включайте файлы с токенами в git репозитории
- Токены дают доступ к личным данным пользователя

|-------------|---------------------|-----------|
| **Пользовательские данные** | ✅ Полный доступ | ❌ Ограничено |
| **Реальные аккаунты FatSecret** | ✅ Да | ❌ Нет |
| **Сложность** | 🔴 Высокая | 🟢 Низкая |
| **Безопасность** | 🔐 Криптографические подписи | 🔒 HTTPS токены |
| **Процесс авторизации** | 🌐 Браузер + PIN | 🤖 Сервер-сервер |

## Устранение неполадок

### "Invalid signature" ошибка
- Проверьте правильность Consumer Key и Consumer Secret
- Убедитесь что системное время корректное

### "Invalid IP address" ошибка  
- Добавьте ваш IP адрес в белый список в настройках FatSecret API

### Браузер не открывается
- Используйте флаг `--no-browser`
- Скопируйте URL вручную в браузер

### Нет записей за дату
- Убедитесь что в FatSecret аккаунте есть записи за указанную дату
- Попробуйте другую дату с известными записями
